## 职位描述（JD）

```text
岗位名称：资深前端开发工程师（中高级）
工作地点：杭州 / 北京（可远程协作）
经验要求：3–5 年前端开发经验

岗位职责：
1. 负责 ToC 小程序与 ToB 中后台的前端架构落地、核心模块开发与性能优化
2. 参与需求评审，推动跨端体验与工程化规范（组件库、CI/CD、质量门禁）
3. 与产品、设计、后端协作，保障弱网、长列表、复杂交互场景的交付质量
4. 沉淀前端最佳实践，参与 Code Review 与技术文档建设

任职要求：
1. 精通 JavaScript / TypeScript，熟悉 HTML / CSS 与现代前端工程化
2. 熟练掌握 React 与 Vue（含 Vue3），有双栈落地经验者优先
3. 有 uni-app 或微信小程序跨端项目上线经验
4. 熟悉 Vite / Webpack、pnpm、ESLint、单元测试与端到端测试
5. 具备中后台复杂表格 / 数据可视化（ECharts 等）实践经验
6. 了解 WebSocket / SSE 等实时通信，能处理查询取消、状态同步等场景
7. 有 Electron 或桌面端经验加分；有微前端（qiankun / Module Federation）经验加分
8. 本科及以上学历，沟通清晰，能独立负责模块并推动上线

加分项：
- 高并发 / 弱网性能优化案例
- 增长分析、投放或数据看板相关经验
- 开源或技术分享经历
```

## 额外要求

突出 React / Vue 双栈、uni-app 跨端、Electron 桌面端与中后台工程化；勿夸大管理经验；按 JD 回填可检索关键词，冷门库不必硬塞进专业技能。
